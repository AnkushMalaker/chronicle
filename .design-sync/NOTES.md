# Chronicle Design System — sync notes

## Origin
This design system was **authored inside Claude Design** (not built by the `/design-sync`
converter). It was reverse-engineered from `backends/advanced/webui/` — lifting the recurring
inline-Tailwind patterns into real tokens + primitives.

- Source project (regular Design type, `PROJECT_TYPE_PROJECT`): `68c42a87-8bda-43b0-a922-63cfb79a3abb`
  ("Wake word lab navigation"). It never compiled a `_ds_bundle.js` because a regular Design
  project is the wrong file type and can't be converted after creation.
- Target project (Design-System type, `PROJECT_TYPE_DESIGN_SYSTEM`): `5025b4e9-fcd4-46a3-848d-d84156afec97`
  ("Chronicle Design System"). Created fresh with the correct type so the app compiles the bundle.

## Layout
This is the Claude-Design-native project format (NOT the converter's output layout):
- Per-group demo cards (`components/<group>/<group>.card.html` with `@dsCard` markers), not
  per-component `.html`.
- Component sources are `components/<group>/<Name>.{jsx,d.ts,prompt.md}` (flat, not per-component dirs).
- `support.js` is the design-canvas (dc-runtime) generated file used by the two `*.dc.html` docs.
- `styles.css` is `@import`-only over `tokens/*.css`.
- `_ds_bundle.js` is **generated by the app** on the design-system side — never uploaded.
