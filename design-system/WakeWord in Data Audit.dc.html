Wake-Word Lab & Data Audit — one umbrella, three formats

You said they're two different tools that belong under one umbrella, and that when you're doing wake-word work you don't want the other views around. That points away from cramming both onto one page. Each option below is your real shell with the Wake-Word Lab recreated from code — the only thing that changes is how you get into it. My pick: 1b (matches "move it into Data Audit" literally) or 1a if you expect more curation tools later. 1c is the tabs idea, shown so you can judge it.

1a

Grouped in the sidebar

A Curation group in the nav holds Data Audit and Wake-Word Lab as two peers. Each stays a full standalone view. Clicking Wake-Word Lab drops you into it with nothing else on screen.

  • Total focus — its own full-screen view
  • Reads as "two tools, one umbrella" right in the nav
  • Scales cleanly if a 3rd curation tool appears
  • Not visually "inside" Data Audit
  • Adds one nav group to learn

1b

A card in the Data Audit hub recommended

Wake-Word Lab becomes the 4th tile on your existing hub. Clicking it opens a dedicated full-screen route (breadcrumb back to the hub) — so it lives inside Data Audit but still gets its own uncluttered view.

  • Literally "moved into" Data Audit
  • Reuses the card pattern already on the hub
  • Opens a full route → no other views in the way
  • One extra click (hub → card) to reach it
  • Hub leans more launcher than workspace

1c

Top tabs on one page

The format you floated: a segmented control at the top of one Data Audit page toggles between Audit & enroll and Wake-Word Lab. Switching hides the other, so the lab does get focus.

  • One click to switch; both on one page
  • Familiar pattern
  • Collides with the inner tabs it already has (Conversations/Archived, clip buckets) — nested tabs get confusing
  • Two heavy tools sharing one route feels less like "its own view"
