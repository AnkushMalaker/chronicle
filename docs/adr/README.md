# Architecture decisions

Architecture Decision Records (ADRs) capture decisions that change Chronicle's
domain model or cross service boundaries. They describe intent and consequences;
the implementation and current-state documentation remain authoritative about what
the running system does today.

Statuses:

- **Proposed**: agreed direction, not yet implemented.
- **Accepted**: implementation is approved and may be in progress.
- **Implemented**: the production path and current-state documentation match the ADR.
- **Superseded**: replaced by a later ADR.
